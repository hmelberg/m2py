## 1. Engine — m2py.py + functions.py

### Correctness bugs

**B1 (HIGH). Compound `if` conditions still hit the string/int dtype mismatch — silent empty result** — `m2py.py:7266-7268` (`_parse_condition` bails on `&`/`|`) + `m2py.py:8814-8818` (fallback to raw `_py_eval_cond`).
The known `summarize x if kjonn == 1` bug **is fixed** for simple conditions (the dtype-aware `_eval_condition_mask` at 7343-7441 tries string candidates). But any compound condition falls back to plain Python eval with no dtype adaptation.
Confirmed: `summarize lonn if kjonn == 1 & alder > 30` → silently returns `Antall = 0`, all NaN, while `summarize lonn if kjonn == 1` works. Same trap for every command in `_COND_FILTER_COMMANDS`.

**B2 (HIGH). `generate ... if <cond>` never uses the dtype-aware mask — silent all-missing column** — `m2py.py:4655-4657` (uses `_py_eval_cond` directly) vs `m2py.py:8680-8682` (only `rename/replace/drop/keep/...` get `_condition_mask`).
Confirmed: `generate mann = 1 if kjonn == 1` → "Genererte mann med 10 000 enheter, hvorav 10 000 missingverdier". `replace` with the identical condition works.

**B3 (HIGH). Label-text conditions never match zero-padded codes — `keep if bosted == 'Oslo'` deletes everything** — `m2py.py:4334-4339` (`_label_key_to_int` converts codelist key `'0301'` → int `301`) + `m2py.py:7304-7311` (`_resolve_condition_value` sets `str_code = '301'`, never the padded original).
Confirmed: `keep if bosted == 'Oslo'` on `'0301'` strings → 0 of 10 000 kept. `bosted == '0301'` works; label comparison silently matches nothing.

**B4 (HIGH). `++` string concatenation in `generate` is broken — including the workaround the tool itself recommends** — `m2py.py:7507-7562` (`_process_pp_in_line` evaluates `++` chains at parse time; column names become NameErrors kept as literals, glued into invalid Python).
Confirmed: `generate composite = string(a) ++ '_' ++ string(b)` → SyntaxError. This exact line is what the multi-key error messages for `collapse by()` and `merge on` recommend (`m2py.py:120, 189-190, 4690-4696`).

**B5 (HIGH). `recode` corrupts string-coded variables that pass through untouched** — `m2py.py:4158` (`pd.to_numeric` on the whole column) + `m2py.py:4291-4294` (round-trip via `str(int(x))`).
Confirmed: `recode bosted (4601 = 1)` on `['0301','4601','5001']` → `['301','1','5001']`; `'XXXX'` → NaN; `'01.110'` → `'1'`.

**B6 (MEDIUM). `if` conditions containing commas are torn apart by the option splitter** — `m2py.py:604-619`.
Confirmed: `summarize lonn if inrange(alder, 30, 40)` → TokenError. Works for whitelisted `keep/drop/replace`, not `summarize/tabulate/regress`. Variant: `summarize lonn, gini if b == 1` silently drops the condition and reports full-population stats.

**B7 (MEDIUM). `collapse (percent)` always returns ~100 per group** — `m2py.py:3610` computes within-group non-missing share, not the group's share of total.

**B8 (MEDIUM). `substr` zero-pads every integer 0-9999, not just municipality codes** — `functions.py:205-239`. Confirmed: `substr(45, 1, 2)` → `'00'`.

**B9 (LOW). `rowconcat` embeds literal `'nan'` for missing values** — `functions.py:338` (`astype(str)` before `fillna`).

**B10 (LOW). `_elementwise` has an inverted None-guard and is dead code** — `functions.py:13-19`.

**B11 (LOW). Duplicate collapse targets silently overwrite** — `m2py.py:4706-4710`: `collapse (mean) x (sd) x, by(g)` — second silently wins.

**B12 (LOW). Dead `"<n> if <cond>"` translation branches** — `m2py.py:4647-4650`, `m2py.py:3976-3985` — unreachable because `parse_line` strips ` if ` first (m2py.py:622-624).

### Disclosure-control gaps (DC on)

**D1 (HIGH, confirmed). `tabulate-panel` and `transitions-panel` have no T5 small-cell check.** `_t5_small_cell_check` is a closure inside the `tabulate` branch (`m2py.py:4921-4948`, called at 5060/5144 only). `tabulate-panel` (5205-5230) and `transitions-panel` (5232-5257) render raw cells of 1, and both are excluded from T7 (`m2py.py:9035`) — zero disclosure checks. `transitions-panel` additionally shows row-normalized transition probabilities from cells of size 1.

**D2 (MEDIUM). Graph commands bypass T5; `barchart`/`piechart`/`hexbin`/`sankey` bypass T2 winsorization.** Histogram (6524-6526), boxplot (6588-6593), scatter (6645-6657) winsorize; `barchart` (6390-6494) does not — `barchart (min) lonn, over(g)` shows the exact group minimum. `piechart` (6693) and discrete `histogram` (6527-6535) show exact small category counts; `sankey` (6786-6795) plots links with count 1 — numbers `tabulate` would refuse.

**D3 (MEDIUM). `tabulate ..., summarize(var)` volume tables skip T2 winsorization and T8 rounding** — `m2py.py:5056-5090` computes raw full-precision group means/p50 while `summarize` winsorizes (4729-4734) and rounds percentiles (4759-4763).

**D4 (MEDIUM). Grouped `summarize, by()` and `summarize-panel` are weaker than plain `summarize`.** T7 checks only `len(df_target)` (m2py.py:9036-9038), never per-group counts — mean/std/min/max printed for a group of 2 (confirmed). `summarize-panel` (4889-4906) applies no winsorization; `gini`/`iqr` in all branches use raw unwinsorized columns (4745-4750, 4764-4767).

**D5 (LOW/MEDIUM). Regression, survival and `coefplot` have no population minimum** — dispatch at m2py.py:9173-9250 runs on any subset ≥1-3 rows; `kaplan-meier ..., by(g)` prints exact per-group N/event counts at any size.

### Inconsistencies / notes

- `replace` gets the dtype-aware condition mask, `generate` does not (B2).
- `_t5_small_cell_check` counts structural-zero cells of a crosstab as "small" — sparse-but-safe 2-way tables can be blocked; worth a deliberate decision.
- `m2py.py:263` `_is_strict_emulation = _is_disclosure_control` — turning DC off also loses pseudonym/string-type strictness checks. Consider two flags.
- 1-D/2-D `tabulate x, cellpct` prints fractions while the header says "pct" (cosmetic).

### Simplifications

1. Hoist `_t5_small_cell_check` to a `StatsEngine` method taking `(df, row_vals, col_vals, dropna)`; call from `tabulate`, `tabulate-panel`, `transitions-panel` (and optionally count plots). Fixes D1/D2, ~30 lines.
2. Extract `_numeric_vars(df, args, exclude=...)` — boilerplate copy-pasted at m2py.py:4722, 4773, 4798, 4848, 4892, 5238.
3. Unify `run_script`/`_run_script_body` with the async variants (m2py.py:7619-7746 vs 7758-7885, ~130 near-identical lines).
4. `_opt_name(options, key, default)` helper for RegressionHandler — idiom repeated ~20×  (5300-5342, 5573-5584, 5654-5673, 5772-5853).
5. Delete dead code: B12 branches and `_elementwise`.

## 2. SDC verbs — protect.py (+ m2py integration)

No hard-coded seeds anywhere (noise unseeded by default, reproducibility opt-in via `random_state`) — correct. All verbs `copy()` before mutating. `_reject_inert_share`, the p%-rule small-contributor handling (1603-1622), and `_profile_k_anonymize`'s fail-loudly final check (2166-2178) are correctly done.

### Privacy bugs

**P1 (HIGH). `swap` silently swaps nothing for small datasets** — `protect.py:1444` (`n_swap = int(round(n * share))`, pairs = `n_swap // 2`). Default `share=0.05` + <~30 rows → 0 pairs; verified 25 rows → 0 values changed, yet `m2py.py:8192` logs success. Same no-op for `level='unit'` (1484-1487).

**P2 (HIGH). `noise(method='group_mean')` is a silent no-op for fractional scale** — `protect.py:290` `k = int(scale)`; `:368` returns column unchanged when `k < 2`. `scale=0.05` (natural — scale means SD elsewhere) → original data, success logged.

**P3 (MEDIUM). Microaggregation leaves the most extreme value unprotected** — `protect.py:371-377`: ascending sort + k-chunks; trailing remainder group of one is replaced by its own mean (unchanged) and holds the largest values. Merge remainder into last full group.

**P4 (HIGH). `risk()` silently ignores every record with a missing quasi-identifier** — `protect.py:1816-1819` `groupby(dropna=True)`. Verified: unique record with NaN quasi-ID invisible → `k_min=5`, `units_at_risk=0`. Overstates safety.

**P5 (MEDIUM). `insert` decoys are trivially filterable** — `protect.py:1275,1287`: IDs `DECOY000000…` — one filter removes them.

**P6 (MEDIUM). HIPAA Safe Harbor ZIP rule tests sample counts, not population** — `protect.py:2037-2039`: `zip_population_threshold` (default 20 000 = the Census-population figure) compared to dataset `value_counts()`.

**P7 (MEDIUM). `_scrub_auto` "protects" numerics with ±1%-of-range jitter** — `m2py.py:8214` + `protect.py:442` — values recoverable to within 1% of range while log says protected.

### Statistical-correctness bugs

**S1 (HIGH). Grouped verbs destroy data in NaN groups** — `winsorize(by=…)` (`protect.py:521`), `collapse(by=…)` (1155), `noise(method='group_mean', by=…)` (381): `groupby(dropna=True)` + assignment back → rows with NaN `by` come back NaN in the data column. Verified.

**S2 (HIGH). `swap(level='unit')` broadcasts the first row's value, not the unit's record** — `protect.py:1516-1523`. Verified: unit incomes [100,200,300] all became 10 — within-unit variation annihilated.

**S3 (MEDIUM). `RiskReport.k_below_5` counts equivalence classes but is reported as records** — computed at 1823, rendered at 1774 as "records with k<5" — ~k times too small.

**S4 (MEDIUM). l-diversity/t-closeness are row-level even when k is unit-level** — 1816 vs 1839-1851/1832 — mixed denominators in one report.

**S5 (MEDIUM). `suppress(ranges=…)` mislabels values below the lowest range** — `protect.py:1630-1636`: value 0 with ranges [(1,5),(6,10)] labels `">10"`.

**S6 (MEDIUM). `bin(labels="range")` doesn't produce documented labels and stringifies NaN** — docstring at 547 promises "10-20"; 577 yields `"(0.999, 2.5]"` and `'nan'` as a real category.

**S7 (MEDIUM). `year`/`month`/`diff` break on NaT** — `year()` raises on any NaT (894); `month()` produces `'2020.0-1.0'`/`'nan-nan'` for all rows once one NaT exists (929); `diff` crashes at 999.

**S8 (LOW). `risk()` crashes on empty DataFrame** — 1821 `int(eq_classes.min())` → ValueError.

**S9 (MEDIUM). `shorten` merges NaN with real codes** — 1063 `astype(str)` before the `pd.isna` guard (dead code at 1055); NaN → `'n'` with `keep=1`.

**S10 (MEDIUM). `collapse` recodes NaN to `other_label`** — 1152: NaN becomes "Other"; also affects `_profile_k_anonymize` and `_profile_health_research`.

**S11 (LOW). `noise` `clip` alters unperturbed rows** — 326-329: post-hoc clip applies to rows not selected by `share`.

### Security

**S1 (HIGH, systemic). GitHub PAT, Anthropic key, auth token in plaintext localStorage on an origin whose core feature is executing scripts in main-thread Pyodide** — `js/github-storage.js:191-192,225` (incl. legacy `m2py_github_pat` migrated but never deleted), `js/ai-chat.js:1493`, `js/login.js:6,137`. **S2 (HIGH). Web-mode AI answers are auto-inserted and auto-executed without confirmation** — `js/ai-chat.js:1236-1279` (extract → insert → run → up to 3 repair rounds). `/api/data-svar` does agentic web search; a poisoned page can prompt-inject arbitrary Python that runs with S1 in reach. **S3 (HIGH). Unescaped `str(result)` HTML injected into `#outputArea` in SafeStat rendering** — `index.html:8964-8972` build `"<pre>" + str(_r)` with no `html.escape`, consumed via `innerHTML` at 8444; remote twins at 8479, 8518. (Strict path escapes correctly at 8651-8652.) Attacker-controlled CSV cell → XSS on the app origin.

**S4 (LOW-MEDIUM). `data-var1`/`data-var2` attribute injection in tablehtml embeds** — `m2py.py:9144-9147` unescaped f-string → `index.html:6008` `innerHTML`.

**S5 (MEDIUM). Share links leak `key(...)` decryption secrets** — `js/github-storage.js:82-105`: `shareLink` gzips raw editor text; `DataDirectives.scrubKeys` (`js/data-directives.js:44`) exists and is used for AI paths but NOT for sharing or GitHub save. Positive: `#s=` links only load into the editor, never auto-run (verified), and the hash is stripped via `history.replaceState`.

**S6 (INFO). Crypto is fundamentally sound** — AES-256-GCM, fresh 12-byte IV per encryption, random 256-bit key, fingerprint recomputed from ciphertext. Minor: `payload_format` not in AAD (csv↔parquet flip possible, cosmetic). Paillier: correct `g = n+1`, per-value randomization; `Math.round(Number(x)*scale)` loses precision above 2^53/scale (data-quality). 1024-bit option offered in encrypt.html UI (labeled "less secure") — consider removing.

**S7.** No unauthenticated postMessage handlers (verified).
