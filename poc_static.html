PoC: DuckDB-WASM querying static Parquet → Pyodide pandas

Proves the integration handshake: DuckDB-WASM (JS) range-queries the static_data/*.parquet files, and the result crosses into Pyodide as a pandas DataFrame. Serve this from the repo root over HTTP (Range support needed):
"C:/ProgramData/anaconda3/python.exe" -m http.server 8000 → open http://localhost:8000/poc_static.html. Open the Network tab to confirm only a fraction of person.parquet (94 MB) is fetched.
